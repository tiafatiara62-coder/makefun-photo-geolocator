A two-pass vision geolocator: it places each of 25 street-level photos with claude-sonnet-5-5 under a structured GeoGuessr-style prompt, then verifies the least-confident photos with claude-opus-5-5, and never leaves a photo unanswered.

## Run it

```sh
node main.ts
```
